# Plåtslageri Site

## Goal

Build a modern, fast and SEO-friendly website for JA Möllers Plåt AB.

The project should later be reusable as a starter template for other local businesses.

---

# Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- Vercel

---

# Current Features

## Public

- Home
- Gallery
- Project pages
- Contact page
- Contact form

## Admin

- Login
- Upload projects
- Edit projects
- Delete projects
- Multiple project images
